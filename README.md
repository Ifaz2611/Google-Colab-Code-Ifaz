# Machine Learning & AI Projects

This repository contains a collection of my Machine Learning and Artificial Intelligence projects, primarily developed using Google Colab and Kaggle.

## Projects

Here's a brief overview of the projects included in this repository:

*   **Asteroid_ML.ipynb**: A project focused on asteroid data analysis and machine learning.
*   **H_F_MODEL.ipynb**: This notebook contains the implementation of the H&F (presumably He and Fu) model.
*   **LFM2_5_2_6B_Training.ipynb**: Training a large-scale model, likely a 2.6 billion parameter model from the LFM2.5 family.
*   **small_smol8btrain.ipynb**: A notebook for training a smaller 8-bit quantized model.



## Usage

Each Jupyter notebook (`.ipynb` file) is a self-contained project. You can run them using Google Colab, Kaggle, or a local Jupyter environment.
